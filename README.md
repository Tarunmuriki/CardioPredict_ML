# CardioPredict_ML

This project demonstrates Decision Tree and Random Forest modeling on a heart disease classification dataset.

## Project Structure

- `datasets/` – place `heart_disease_dataset.csv` here
- `notebooks/` – Jupyter notebook analysis
- `results/` – plots and model visualizations saved here
- `decision_tree_random_forest.py` – reproducible training and evaluation script
- `project_report.md` – summary of findings
- `dependencies.txt` – required Python packages

## How to Use

1. Install dependencies:
   ```bash
   pip install -r dependencies.txt
   ```
2. Place the heart disease CSV in `datasets/heart_disease_dataset.csv`.
3. Run the analysis:
   ```bash
   python decision_tree_random_forest.py
   ```
4. Review saved outputs in `results/`.
